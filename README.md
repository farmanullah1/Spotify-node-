# Spotify-node-

Spotify Clone backend built with Node.js, Express, MSSQL, and ImageKit.

## Features
- User Authentication (Registration, Login with username or email, Logout, JWT with httpOnly cookies & Bearer token).
- Role-based Access Control (`user` vs `artist`).
- Music Track Upload (ImageKit cloud integration, audio MIME type validation).
- Album Management (Linking albums to tracks & artists).
- MSSQL database with connection pooling.
